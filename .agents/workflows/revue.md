# Workflow : /revue
Relis le code modifie depuis le dernier commit comme un reviewer senior.
Classe les remarques en : Bloquant, Important, Amelioration.
Pour chaque remarque : fichier et ligne, explication simple, correction proposee.
Verifie en priorite : securite, validation des entrees, gestion des erreurs, doublons de code, noms.
Ne corrige rien sans mon accord.
